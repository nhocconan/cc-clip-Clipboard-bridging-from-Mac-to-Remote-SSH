## What's New in v0.13.3

The SSH screen wrapper now waits for a silent clipboard tunnel to recover or
release its port after a VPN switch, instead of stopping immediately. It
rechecks for up to 120 seconds by default; set `CC_CLIP_FORWARD_WAIT_SECONDS`
to change the wait, or use `0` to stop immediately.

Automatic port release requires server-side SSH keepalives. The troubleshooting
guide shows how an administrator can configure `ClientAliveInterval 15` and
`ClientAliveCountMax 3` for one remote user. The wrapper never kills remote
sessions automatically and never changes the server configuration itself.

## Other Improvements

- Failed listener checks remain unverified instead of being mistaken for a free port.
- Regression tests cover delayed port release, recovery of an existing tunnel,
  bounded waiting, and failed listener checks.
- Release archives now include `scripts/ssh-cc-clip.sh`.
- Includes the persistent screen reconnect wrapper introduced since v0.13.2,
  with child cleanup on terminal closure and a lock against duplicate wrappers.
- Clipboard image fetches use a 15-second default timeout; clipboard text
  writes keep their separate 5-second timeout.

## Upgrade

Existing fork installations can update the binary with `cc-clip update`.
The reconnect wrapper is installed separately; updating the binary does not
replace a copy in `~/scripts`:

```bash
mkdir -p ~/scripts
curl -fsSL https://raw.githubusercontent.com/nhocconan/cc-clip-Clipboard-bridging-from-Mac-to-Remote-SSH/v0.13.3/scripts/ssh-cc-clip.sh -o ~/scripts/ssh-cc-clip.sh
chmod +x ~/scripts/ssh-cc-clip.sh
~/scripts/ssh-cc-clip.sh myserver
```

After updating the binary, redeploy to each remote with
`cc-clip connect <host> --force`. Fresh macOS/Linux installations can use
`scripts/install.sh`; Windows installations can use `scripts/install.ps1`
from this repository. The Bash screen wrapper is for macOS/Linux SSH clients.

## Limitations

The wrapper cannot release an existing stale server session itself. Configure
server-side keepalives for new connections and use the troubleshooting guide
to identify an old holder before ending it. A healthy existing tunnel is
checked by service name; authenticated installation identity checks remain
available through `cc-clip tunnel run`.

## Verification

Download the archive and `checksums.txt` from this release. For macOS arm64:

```bash
shasum -a 256 cc-clip_0.13.3_darwin_arm64.tar.gz
grep 'cc-clip_0.13.3_darwin_arm64.tar.gz' checksums.txt
```

The hashes must match before extracting or running the archive.
