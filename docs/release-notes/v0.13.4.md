## What's New in v0.13.4

Text copied through the macOS daemon now keeps its UTF-8 encoding when launchd
starts the service without a locale, or when `LC_ALL=C` is inherited. Both
`pbcopy` and `pbpaste` receive a UTF-8 locale. This imports
[the upstream fix](https://github.com/ShunmeiCho/cc-clip/commit/613a1af2ca88ccfa73cf9aa9aa1ec96d54842e73)
and its regression tests.

## Maintenance

- Active installation, upgrade, troubleshooting, and contribution guides point
  to this maintained fork. Rollback examples use releases published by the fork.
- CI runs native macOS race tests in addition to Linux and Windows checks.
  Weekly runs also check for newly disclosed Go vulnerabilities.
- Dependabot checks Go modules and pinned GitHub Actions weekly.
- The Antigravity Stop adapter test includes the metadata introduced in agy
  1.5.4 and verifies that notification content and the required decision response
  remain unchanged.

## CLI Compatibility

The current Claude Code Stop/Notification hooks, Codex user-level `notify`
command, and Antigravity Stop hook remain the integration points. This release
does not migrate existing hooks or enable a second notification path.

The integration contracts were checked against the current
[Claude Code hook reference](https://code.claude.com/docs/en/hooks),
[Codex configuration reference](https://learn.chatgpt.com/docs/config-file/config-reference),
and [Antigravity hook reference](https://antigravity.google/docs/hooks/).
Adapter tests cover these contracts; a complete interactive image-paste test
with every latest CLI version has not been performed.

## Upgrade

```sh
cc-clip update --to v0.13.4
cc-clip connect <host> --force
cc-clip doctor --host <host>
```

Use the same target flags you originally deployed, such as `--codex`, `--agy`,
or `--all`, with `connect`. The SSH wrapper has not changed since v0.13.3.

[Full diff from v0.13.3](https://github.com/nhocconan/cc-clip-Clipboard-bridging-from-Mac-to-Remote-SSH/compare/v0.13.3...v0.13.4)
