## What's New in v0.13.2

First release of nhocconan's personal fork of ShunmeiCho/cc-clip.

- Deploy commands no longer inherit SSH reverse forwards, avoiding port conflicts with existing sessions. SSH failures now include the original diagnostic.
- `--agy` installs the clipboard shim for Antigravity image paste, including with `--no-notify`. Verified with agy 1.4.10 on two Linux hosts. On headless hosts, launch with `DISPLAY=:0 agy`.
- Installers, updates and remote binary downloads use this fork's releases.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/nhocconan/cc-clip-Clipboard-bridging-from-Mac-to-Remote-SSH/main/scripts/install.sh | sh
```

Existing installations built from this fork can run `cc-clip update`.
